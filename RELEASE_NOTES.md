# Nova Server v1.6.1

A small docs patch.

## Changed

- The in-panel Inbounds guide now describes the **per-inbound traffic chart** (the daily traffic each inbound carried over the last 14 days), in English, Persian, and Russian. No functional change; the chart itself shipped in 1.5.0.

## Install

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/IRNova/Nova-Server/main/nova-node.sh)
```

Existing nodes update themselves from Settings > Updates.
