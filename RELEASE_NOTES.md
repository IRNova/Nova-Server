# Nova Server v1.23.0

Less friction: fewer re-logins, and the subscription is one obvious click.

## Changed

- **Far fewer re-logins.** The panel session now lasts 8 hours of inactivity instead of 30 minutes, and the login screen has a **Keep me signed in for 30 days** option (on by default). No more entering your password every time you come back to make a change, especially on a flaky connection. Sessions stay pinned to your browser and are still invalidated the moment you change your password.
- **Getting a subscription is now obvious.** Each user row has a clear **Connect** button (QR + copyable link + open-in-app), so you no longer have to open Edit to find the subscription. The quick copy-link icon is still there too.

## Notes

- Existing nodes pick this up through the version-gated update. Nova Server ships as an obfuscated build by design; the installer and verified tools stay open.
